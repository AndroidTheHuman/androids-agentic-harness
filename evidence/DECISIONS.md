# Decision log

The decisions that shaped the harness, in order. Each one names what prompted it, what changed, and where it is recorded in the game repo (*Infinity Autobattler*, private; available on request). "Memory" means a Claude Code memory file: owner preferences that every session loads.

The pattern across all twelve: **a failure or a measurement first, then a rule, then a check that enforces the rule.** Decision 1 answers failures from the earlier project; each later one answers something that happened here.
